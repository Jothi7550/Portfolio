JOTHIVEL PORTFOLIO WEBSITE

Files:
- index.html: portfolio content
- style.css: layout, responsive design, and kitten-inspired colours
- script.js: mobile navigation and current year
- assets/cat-reference.jpg: your supplied kitten image

To view:
1. Extract the ZIP file.
2. Open the jothivel-portfolio folder.
3. Double-click index.html.

The website functionality uses only HTML, CSS, and JavaScript.
Google Fonts loads over the internet; fallback fonts are included.
